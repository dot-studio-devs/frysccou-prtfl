2) DOCUMENTACIÓN VISUAL


Se busca dar una imagen profesional, minimalista y cálida, con un toque artesanal — limpio pero con personalidad, lejos del corporate frío.


Paleta cromática

Color principal — Lila / Lavanda suave → transmite creatividad, calma y un costado amable, poco saturado. Funciona como sello de marca sin agredir.

Color secundario — Morado profundo → versión más intensa del principal, se usa para acentos, links activos y detalles tipográficos. Aporta seriedad y contraste.

Color base — Blanco → transmite estabilidad, armonía y deja respirar al contenido. Es la superficie principal del sitio.

Color neutro — Gris carbón → para títulos y textos largos. Reemplaza al negro puro para evitar dureza visual y mantener elegancia.

Color de soporte — Gris claro / off-white → para fondos secundarios, tarjetas y separadores sutiles. Genera jerarquía sin romper la limpieza.

Acento extra — Verde lima → uso muy puntual (estados activos, indicadores de "disponible", micro-detalles). Aporta vitalidad sin saturar.


Tipografía

Títulos / nombre → Bodoni o Cormorant Garamond (serif de alto contraste) → transmiten elegancia, refinamiento y un aire editorial / artesanal. Le dan personalidad al portfolio sin caer en lo decorativo.

Cuerpo de texto → Sans Serif limpia (tipo Inter u Outfit) → altamente legible, neutra y moderna. Ideal para párrafos largos y UI.

Detalles técnicos / código / metadata → Monospace (tipo JetBrains Mono o Geist Mono) → refuerza el lado "developer", aporta ritmo visual distinto y se asocia bien con la identidad de Full Stack.
